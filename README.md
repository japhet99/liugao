扩展名称

留稿 · 网页输入保护

简短描述

自动保存授权网站的文本草稿，右键恢复输入历史，减少误删、刷新造成的重复填写。无需账号，仅本机保存。

详细介绍

写了一大段内容，却因为误删、刷新页面或关闭编辑窗口，需要重新输入？

留稿会在你开启保护的网站自动保存文本草稿，帮助你找回已经保存的输入内容。适合填写网页表单、编辑商品资料、撰写评论等场景。

主要功能：
- 自动保存输入：在授权网站保存支持的文本框和可编辑区域中的纯文本。
- 右键恢复历史：在输入框内右键，选择之前保存的内容，直接恢复到原位置。
- 快捷键恢复：按 Alt+Q 恢复当前输入框最近一个不同的保存值；按 Alt+Shift+Q 恢复当前页面能可靠匹配的字段。
- 选择字段恢复：查看草稿版本，对照网页当前内容，只恢复需要的字段。
- 覆盖前自动备份：恢复时先备份原有非空内容，并支持撤销上次留稿填充。
- 自行控制保护范围：按网站开启或暂停保护，也可以单独停止保存某个输入框。
- 仅本机保存：无需注册账号，不上传草稿，不使用云同步。
使用方法：
1. 打开需要保护的网站，点击留稿图标。
2. 选择「添加并开启保护」，阅读说明并授权。
3. 正常输入；需要找回内容时，在输入框内右键选择历史，或进入「历史记录」查看草稿。
使用说明：

留稿仅能恢复已经成功保存的内容，无法找回安装或开启保护之前丢失的输入。支持范围取决于网页结构，暂不支持 iframe、Shadow DOM、图片及附件，也不保留富文本格式。

草稿不按时间自动删除，但受历史版本数量和本地容量限制。卸载扩展会删除本地草稿。

密码字段不保存，识别出的验证码、支付及证件等敏感字段会被跳过。普通文本中的敏感信息可能无法全部识别，请谨慎选择开启保护的网站。
